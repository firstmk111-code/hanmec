  1. GitHub 로그인 → 우측 상단 프로필 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token → Repository access 에서 firstmk111-code/hanmec 선택
  4. Permissions → Repository permissions → Contents 를 Read and write 로 설정
  5. 생성된 토큰(github_pat_…)을 복사해 위에 붙여넣기

이미지 관리

홈페이지에 쓰인 이미지를 메뉴별로 나눠서 보여줍니다. 바꾸고 싶은 이미지의 교체 버튼을 눌러 새 이미지를 올린 뒤, 우측 상단 저장하고 발행을 누르면 홈페이지에 반영됩니다.

텍스트 관리

페이지를 고른 뒤 문구를 직접 고칩니다. 수정한 항목은 노란색으로 표시됩니다.

주요실적 관리

카테고리별 납품 실적을 추가·수정·삭제하고 사진을 등록합니다.

제품상세 페이지

홈페이지 제품소개 > 제품 상세 화면을 수정합니다. 제품 사진·설명과 사양표를 직접 고칠 수 있고, 표는 행을 추가하거나 지울 수 있습니다.
